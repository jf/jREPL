# an enhanced Node.js REPL

provides:
- timestamped prompts
- `j_typeof` (as a function), which detects and reveals more types than your standard `typeof`

## Usage

```
$ git clone https://github.com/jf/jREPL.git /path/to/clone/to
$ cd /your/node/project && node /path/to/clone/to/jrepl.mjs
```
